Why soroban-go-toolkit?

Most Soroban tooling focuses on Rust and JavaScript. Go powers backend infrastructure, indexers, and services — but Go developers had to hand-roll RPC calls and decode XDR manually.

This project provides idiomatic, typed Go bindings for Stellar Soroban RPC — so you can focus on building, not boilerplate.

Features

Complete RPC Client

Typed request/response structs for all major Soroban RPC methods with proper error handling.

Ready-to-Use CLI

Command-line interface wrapping all client functionality for scripting and automation.

Zero Dependencies

Standard library only — no external dependencies to manage or conflict with.

Well Tested

Comprehensive test suite with CI validation ensuring reliability.

MIT Licensed

Regular updates and responsive support for the Go Soroban ecosystem.

Quick Start

Get started in under a minute with this simple example that reads from the Stellar testnet. 

package main

import (
	"context"
	"fmt"
	"log"

	"github.com/Northbound-Dev/soroban-go-toolkit/pkg/soroban"
)

func main() {
	// Targets public Stellar testnet by default
	client, err := soroban.New()
	if err != nil {
		log.Fatal(err)
	}

	ctx := context.Background()

	// Check endpoint health
	health, err := client.GetHealth(ctx)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("endpoint status:", health.Status)

	// Get latest ledger
	ledger, err := client.GetLatestLedger(ctx)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("latest ledger: %d (protocol %d)\n", ledger.Sequence, ledger.ProtocolVersion)
}
